# menubot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go binary that posts the Casino Catering lunch menu to a Telegram chat — today's menu Mon–Fri 10:00, next week's menu on Friday afternoon — triggered by systemd timers on a Raspberry Pi.

**Architecture:** One-shot CLI (`menubot daily|weekly|notify-failure`). Pure packages for parsing (`menu`), message text (`format`) and state (`state`); thin HTTP adapters (`fetch`, `telegram`); `jobs` holds the decision logic with injected clock/fetcher/sender. Scheduling, retries and failure hooks live in systemd unit files; `deploy.sh` cross-compiles on the Mac and installs over SSH.

**Tech Stack:** Go (local toolchain 1.27), `golang.org/x/net/html`, stdlib `net/http`, `log/slog`, `encoding/json`; systemd ≥ 244 (Pi OS Bookworm: 252); bash.

**Spec:** `docs/superpowers/specs/2026-10-11-menubot-design.md`

## Global Constraints

- Module path: `github.com/paulwyszynski/mri-casino-menu`.
- Only external Go dependency: `golang.org/x/net`.
- Timezone for all schedule logic: `Europe/Berlin`; binary embeds tzdata (`import _ "time/tzdata"`).
- Build target: `GOOS=linux GOARCH=arm64 CGO_ENABLED=0`.
- Daily window: Mon–Fri, before 14:00. Weekly window: Friday 15:00–20:59.
- Message `parse_mode=HTML`; dish text HTML-escaped; allergen codes removed; prices kept as `9,00 €`; special marked `⭐`.
- No-menu text: `Für heute (Mo, 12.10.) ist kein Speiseplan online.`
- Failure text: `⚠️ Speiseplan konnte nicht abgerufen werden (<unit>). Details: <code>journalctl -u <unit></code>` where `<unit>` is the full unit name, e.g. `menubot-daily.service`; at most one per Berlin calendar day across all jobs.
- State: one file `$STATE_DIR/state.json` with `weekly_sent` (e.g. `2026-W42`) and `failure_notified` (e.g. `2026-10-16`); atomic writes; missing/corrupt → empty.
- Env: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (required unless `--dry-run`), `MENU_URL` (default `https://casinocatering.de/speiseplan/`), `STATE_DIR` (default `$STATE_DIRECTORY`, else `.`).
- Services run as fixed system user `menubot`, `StateDirectory=menubot`, `EnvironmentFile=/etc/menubot/env` (mode 600).
- Tests never touch the live network.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Bot token leaking into logs:** Go's `*url.Error` includes the request URL, which contains the token (`/bot<TOKEN>/sendMessage`). A network error would print the token to the journal. Expected: errors never contain the token. → test in Task 4.
2. **Non-breaking spaces and bullet/price variants from WordPress:** `&nbsp;` in headings, `–`/`-`/`*` bullets, `9€`, `9.50 €`, `11,5€`. Expected: still parsed, prices normalised to `9,00 €` / `9,50 €`. → tests in Task 1.
3. **Year boundary:** Friday 2026-12-25, next week is Mon 28 Dec 2026 – Fri 1 Jan 2027 (ISO week `2026-W53`). Expected: sent once, key `2026-W53`. → test in Task 5.
4. **State save fails after a successful weekly send** (e.g. permission problem): returning an error would make systemd restart the job and resend the menu 3 more times. Expected: log at ERROR, return nil. → test in Task 5.
5. **Clock not yet synced right after boot** (Pi has no RTC; `Persistent=true` catch-up could run with the last-shutdown time). Expected: services wait for `time-sync.target`. → `systemd-analyze verify` + `install.sh` enabling `systemd-time-wait-sync.service` in Task 7.

```go
// Package menu parses the Casino Catering "Speiseplan" page.
package menu

import (
	"errors"
	"fmt"
	"time"
)

// ErrNoMenu is returned when the page contains no recognisable day.
var ErrNoMenu = errors.New("menu: no days found on page")

// Date is a calendar date without time or location.
type Date struct {
	Year  int
	Month time.Month
	Day   int
}

// DateOf returns the calendar date of t in t's location.
func DateOf(t time.Time) Date {
	y, m, d := t.Date()
	return Date{y, m, d}
}

// Time returns midnight UTC of d.
func (d Date) Time() time.Time {
	return time.Date(d.Year, d.Month, d.Day, 0, 0, 0, 0, time.UTC)
}

func (d Date) Weekday() time.Weekday { return d.Time().Weekday() }

func (d Date) AddDays(n int) Date { return DateOf(d.Time().AddDate(0, 0, n)) }

func (d Date) Before(o Date) bool { return d.Time().Before(o.Time()) }

func (d Date) String() string {
	return fmt.Sprintf("%04d-%02d-%02d", d.Year, int(d.Month), d.Day)
}

// Dish is one menu line. Price is normalised to "9,00 €" and empty when the
// line has no price.
type Dish struct {
	Name  string
	Price string
}

// Day is the menu of one date, in page order.
type Day struct {
	Date   Date
	Dishes []Dish
}
```

`internal/menu/parse.go`:

```go
package menu

import (
	"fmt"
	"io"
	"regexp"
	"strconv"
	"strings"
	"time"

	"golang.org/x/net/html"
	"golang.org/x/net/html/atom"
)

// Parse extracts the days from the page. Date headings (<h1>–<h6>) start a
// day, any other heading ends it, and <a class="elementor-toggle-title">
// elements are the dishes of the current day.
func Parse(r io.Reader) ([]Day, error) {
	doc, err := html.Parse(r)
	if err != nil {
		return nil, fmt.Errorf("menu: parse html: %w", err)
	}

	var days []Day
	cur := -1
	var walk func(n *html.Node)
	walk = func(n *html.Node) {
		if n.Type == html.ElementNode {
			switch {
			case isHeading(n):
				if date, ok := parseDate(clean(textOf(n))); ok {
					days = append(days, Day{Date: date})
					cur = len(days) - 1
				} else {
					cur = -1
				}
				return
			case n.DataAtom == atom.A && hasClass(n, "elementor-toggle-title"):
				if cur >= 0 {
					if dish, ok := parseDish(textOf(n)); ok {
						days[cur].Dishes = append(days[cur].Dishes, dish)
					}
				}
				return
			}
		}
		for c := n.FirstChild; c != nil; c = c.NextSibling {
			walk(c)
		}
	}
	walk(doc)

	if len(days) == 0 {
		return nil, ErrNoMenu
	}
	for _, d := range days {
		if len(d.Dishes) == 0 {
			return nil, fmt.Errorf("menu: %s has no dishes", d.Date)
		}
	}
	return days, nil
}

func isHeading(n *html.Node) bool {
	switch n.DataAtom {
	case atom.H1, atom.H2, atom.H3, atom.H4, atom.H5, atom.H6:
		return true
	}
	return false
}

func hasClass(n *html.Node, class string) bool {
	for _, a := range n.Attr {
		if a.Key == "class" {
			for _, c := range strings.Fields(a.Val) {
				if c == class {
					return true
				}
			}
		}
	}
	return false
}

func textOf(n *html.Node) string {
	var b strings.Builder
	var walk func(*html.Node)
	walk = func(n *html.Node) {
		if n.Type == html.TextNode {
			b.WriteString(n.Data)
		}
		for c := n.FirstChild; c != nil; c = c.NextSibling {
			walk(c)
		}
	}
	walk(n)
	return b.String()
}

// clean turns non-breaking spaces into spaces, collapses whitespace and trims.
func clean(s string) string {
	s = strings.ReplaceAll(s, " ", " ")
	return strings.Join(strings.Fields(s), " ")
}

var dateRe = regexp.MustCompile(`(?i)^(?:montag|dienstag|mittwoch|donnerstag|freitag|samstag|sonntag)\s*,?\s*(\d{1,2})\s*[.,]?\s*(\p{L}+)\s*,?\s*(\d{4})$`)

var months = map[string]time.Month{
	"januar": time.January, "februar": time.February, "märz": time.March,
	"maerz": time.March, "april": time.April, "mai": time.May,
	"juni": time.June, "juli": time.July, "august": time.August,
	"september": time.September, "oktober": time.October,
	"november": time.November, "dezember": time.December,
}

// parseDate parses a cleaned heading such as "Montag ,12, Oktober 2026".
// The weekday word is required but not checked against the date.
func parseDate(s string) (Date, bool) {
	m := dateRe.FindStringSubmatch(s)
	if m == nil {
		return Date{}, false
	}
	day, _ := strconv.Atoi(m[1])
	month, ok := months[strings.ToLower(m[2])]
	if !ok {
		return Date{}, false
	}
	year, _ := strconv.Atoi(m[3])
	d := Date{year, month, day}
	if DateOf(d.Time()) != d { // rejects e.g. 31 February
		return Date{}, false
	}
	return d, true
}

var (
	priceRe    = regexp.MustCompile(`(\d{1,3}(?:[.,]\d{1,2})?)\s*€`)
	allergenRe = regexp.MustCompile(`(?i)\(\s*(?:[a-z]\d?|\d{1,2})(?:\s*,\s*(?:[a-z]\d?|\d{1,2}))*\s*\)`)
)

// parseDish turns a raw dish line into a Dish: bullet, price and allergen
// codes are removed from the name; the price is kept separately.
func parseDish(raw string) (Dish, bool) {
	s := clean(raw)
	s = strings.TrimLeft(s, "•·*-– ")
	var price string
	if m := priceRe.FindStringSubmatchIndex(s); m != nil {
		price = normalizePrice(s[m[2]:m[3]])
		s = s[:m[0]] + " " + s[m[1]:]
	}
	s = allergenRe.ReplaceAllString(s, " ")
	s = strings.TrimRight(clean(s), " ,-–")
	if s == "" {
		return Dish{}, false
	}
	return Dish{Name: s, Price: price}, true
}

// normalizePrice turns "9", "9.5", "9,50" into "9,00 €", "9,50 €", "9,50 €".
func normalizePrice(p string) string {
	p = strings.ReplaceAll(p, ".", ",")
	euros, cents, found := strings.Cut(p, ",")
	if !found {
		cents = "00"
	}
	if len(cents) == 1 {
		cents += "0"
	}
	return euros + "," + cents + " €"
}
```

```go
// Package format builds the Telegram message texts (parse_mode=HTML).
package format

import (
	"fmt"
	"html"
	"strings"
	"time"

	"github.com/paulwyszynski/mri-casino-menu/internal/menu"
)

var weekdays = map[time.Weekday]string{
	time.Monday: "Montag", time.Tuesday: "Dienstag", time.Wednesday: "Mittwoch",
	time.Thursday: "Donnerstag", time.Friday: "Freitag",
	time.Saturday: "Samstag", time.Sunday: "Sonntag",
}

var weekdaysShort = map[time.Weekday]string{
	time.Monday: "Mo", time.Tuesday: "Di", time.Wednesday: "Mi",
	time.Thursday: "Do", time.Friday: "Fr", time.Saturday: "Sa", time.Sunday: "So",
}

// Day is the daily message.
func Day(d menu.Day) string {
	var b strings.Builder
	fmt.Fprintf(&b, "🍽 <b>Speiseplan %s</b>\n\n", dayLabel(d.Date))
	writeDishes(&b, d.Dishes)
	return strings.TrimRight(b.String(), "\n")
}

// Week is the weekly message. days must be non-empty.
func Week(days []menu.Day) string {
	var b strings.Builder
	first, last := days[0].Date, days[len(days)-1].Date
	fmt.Fprintf(&b, "📅 <b>Speiseplan nächste Woche (%s)</b>\n", dateRange(first, last))
	for _, d := range days {
		fmt.Fprintf(&b, "\n<b>%s</b>\n", dayLabel(d.Date))
		writeDishes(&b, d.Dishes)
	}
	return strings.TrimRight(b.String(), "\n")
}

// NoMenu is the notice sent when today is not on the page.
func NoMenu(d menu.Date) string {
	return fmt.Sprintf("Für heute (%s, %s) ist kein Speiseplan online.",
		weekdaysShort[d.Weekday()], dayMonth(d))
}

// Failure is the notice sent when a job failed for good.
func Failure(unit string) string {
	u := html.EscapeString(unit)
	return fmt.Sprintf("⚠️ Speiseplan konnte nicht abgerufen werden (%s). Details: <code>journalctl -u %s</code>", u, u)
}

func writeDishes(b *strings.Builder, dishes []menu.Dish) {
	for _, d := range dishes {
		name := html.EscapeString(d.Name)
		if d.Price != "" {
			fmt.Fprintf(b, "⭐ %s – %s\n", name, html.EscapeString(d.Price))
		} else {
			fmt.Fprintf(b, "• %s\n", name)
		}
	}
}

func dayLabel(d menu.Date) string {
	return weekdays[d.Weekday()] + ", " + dayMonth(d)
}

func dayMonth(d menu.Date) string {
	return fmt.Sprintf("%02d.%02d.", d.Day, int(d.Month))
}

func dateRange(a, b menu.Date) string {
	switch {
	case a == b:
		return dayMonth(a)
	case a.Year == b.Year && a.Month == b.Month:
		return fmt.Sprintf("%02d.–%s", a.Day, dayMonth(b))
	default:
		return dayMonth(a) + "–" + dayMonth(b)
	}
}
```

```go
// Package state persists the little the bot must remember between runs.
package state

import (
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
)

// State holds only the latest value of each field.
type State struct {
	WeeklySent      string `json:"weekly_sent,omitempty"`
	FailureNotified string `json:"failure_notified,omitempty"`
}

// Store reads and writes State as JSON at Path.
type Store struct {
	Path     string
	ReadOnly bool
}

// New returns a store for dir/state.json. A read-only store never writes
// (used for --dry-run).
func New(dir string, readOnly bool) *Store {
	return &Store{Path: filepath.Join(dir, "state.json"), ReadOnly: readOnly}
}

// Load returns the stored state. A missing file is an empty state. A file
// that cannot be read or decoded also yields an empty state, together with
// an error the caller should log and otherwise ignore.
func (s *Store) Load() (State, error) {
	data, err := os.ReadFile(s.Path)
	if errors.Is(err, fs.ErrNotExist) {
		return State{}, nil
	}
	if err != nil {
		return State{}, fmt.Errorf("state: read %s: %w", s.Path, err)
	}
	var st State
	if err := json.Unmarshal(data, &st); err != nil {
		return State{}, fmt.Errorf("state: decode %s: %w", s.Path, err)
	}
	return st, nil
}

// Save writes st atomically: temp file, fsync, rename.
func (s *Store) Save(st State) error {
	if s.ReadOnly {
		return nil
	}
	data, err := json.MarshalIndent(st, "", "  ")
	if err != nil {
		return fmt.Errorf("state: encode: %w", err)
	}
	tmp := s.Path + ".tmp"
	f, err := os.OpenFile(tmp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0o644)
	if err != nil {
		return fmt.Errorf("state: %w", err)
	}
	if _, err := f.Write(append(data, '\n')); err != nil {
		f.Close()
		os.Remove(tmp)
		return fmt.Errorf("state: write: %w", err)
	}
	if err := f.Sync(); err != nil {
		f.Close()
		os.Remove(tmp)
		return fmt.Errorf("state: sync: %w", err)
	}
	if err := f.Close(); err != nil {
		os.Remove(tmp)
		return fmt.Errorf("state: close: %w", err)
	}
	if err := os.Rename(tmp, s.Path); err != nil {
		os.Remove(tmp)
		return fmt.Errorf("state: rename: %w", err)
	}
	return nil
}
```

```go
// Package fetch downloads the menu page.
package fetch

import (
	"context"
	"fmt"
	"io"
	"net/http"
	"time"
)

const maxBody = 5 << 20 // 5 MiB; the page is ~90 KB

// HTTP fetches URL with a plain GET.
type HTTP struct {
	URL    string
	Client *http.Client
}

func New(url string) *HTTP {
	return &HTTP{URL: url, Client: &http.Client{Timeout: 20 * time.Second}}
}

func (h *HTTP) Fetch(ctx context.Context) ([]byte, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, h.URL, nil)
	if err != nil {
		return nil, fmt.Errorf("fetch: %w", err)
	}
	req.Header.Set("User-Agent", "menubot/1.0 (+https://github.com/paulwyszynski/mri-casino-menu)")
	resp, err := h.Client.Do(req)
	if err != nil {
		return nil, fmt.Errorf("fetch: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("fetch %s: unexpected status %s", h.URL, resp.Status)
	}
	body, err := io.ReadAll(io.LimitReader(resp.Body, maxBody))
	if err != nil {
		return nil, fmt.Errorf("fetch %s: read body: %w", h.URL, err)
	}
	return body, nil
}
```

```go
// Package telegram sends messages through the Telegram Bot API.
package telegram

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"net/http"
	"net/url"
	"time"
)

type Client struct {
	BaseURL string
	Token   string
	ChatID  string
	HTTP    *http.Client
}

func New(token, chatID string) *Client {
	return &Client{
		BaseURL: "https://api.telegram.org",
		Token:   token,
		ChatID:  chatID,
		HTTP:    &http.Client{Timeout: 20 * time.Second},
	}
}

type sendRequest struct {
	ChatID    string `json:"chat_id"`
	Text      string `json:"text"`
	ParseMode string `json:"parse_mode"`
}

type apiResponse struct {
	OK          bool   `json:"ok"`
	Description string `json:"description"`
}

// Send posts text (Telegram HTML) to the configured chat.
func (c *Client) Send(ctx context.Context, text string) error {
	body, err := json.Marshal(sendRequest{ChatID: c.ChatID, Text: text, ParseMode: "HTML"})
	if err != nil {
		return fmt.Errorf("telegram: encode: %w", err)
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost,
		c.BaseURL+"/bot"+c.Token+"/sendMessage", bytes.NewReader(body))
	if err != nil {
		return errors.New("telegram: cannot build request")
	}
	req.Header.Set("Content-Type", "application/json")

	resp, err := c.HTTP.Do(req)
	if err != nil {
		// *url.Error embeds the URL, which contains the bot token.
		var uerr *url.Error
		if errors.As(err, &uerr) {
			err = uerr.Err
		}
		return fmt.Errorf("telegram: send: %w", err)
	}
	defer resp.Body.Close()

	var r apiResponse
	if err := json.NewDecoder(io.LimitReader(resp.Body, 1<<20)).Decode(&r); err != nil {
		return fmt.Errorf("telegram: %s: decode response: %w", resp.Status, err)
	}
	if !r.OK {
		return fmt.Errorf("telegram: %s: %s", resp.Status, r.Description)
	}
	return nil
}
```

```go
// Package jobs decides what to send and when. Scheduling itself is done by
// systemd; every job checks its own time window so late catch-up runs are
// harmless.
package jobs

import (
	"bytes"
	"context"
	"fmt"
	"log/slog"
	"time"

	"github.com/paulwyszynski/mri-casino-menu/internal/format"
	"github.com/paulwyszynski/mri-casino-menu/internal/menu"
	"github.com/paulwyszynski/mri-casino-menu/internal/state"
)

type Fetcher interface {
	Fetch(ctx context.Context) ([]byte, error)
}

type Sender interface {
	Send(ctx context.Context, text string) error
}

type Deps struct {
	Fetcher Fetcher
	Sender  Sender
	State   *state.Store
	Log     *slog.Logger
}

// Daily sends today's menu, or a notice if today is not on the page.
// It does nothing on weekends and from 14:00 on (lunch is over).
func Daily(ctx context.Context, now time.Time, d Deps) error {
	if wd := now.Weekday(); wd == time.Saturday || wd == time.Sunday || now.Hour() >= 14 {
		d.Log.Info("outside daily window, skipping", "now", now.Format(time.DateTime))
		return nil
	}
	days, err := fetchMenu(ctx, d)
	if err != nil {
		return err
	}
	today := menu.DateOf(now)
	for _, day := range days {
		if day.Date == today {
			return d.Sender.Send(ctx, format.Day(day))
		}
	}
	d.Log.Info("no menu for today on page", "date", today)
	return d.Sender.Send(ctx, format.NoMenu(today))
}

// Weekly sends next week's menu once, on Friday 15:00–20:59, as soon as the
// page shows next week.
func Weekly(ctx context.Context, now time.Time, d Deps) error {
	if now.Weekday() != time.Friday || now.Hour() < 15 || now.Hour() > 20 {
		d.Log.Info("outside weekly window, skipping", "now", now.Format(time.DateTime))
		return nil
	}
	nextMon := mondayOf(menu.DateOf(now)).AddDays(7)
	nextFri := nextMon.AddDays(4)
	year, week := nextMon.Time().ISOWeek()
	key := fmt.Sprintf("%d-W%02d", year, week)

	st := load(d)
	if st.WeeklySent == key {
		d.Log.Info("weekly menu already sent", "week", key)
		return nil
	}

	days, err := fetchMenu(ctx, d)
	if err != nil {
		return err
	}
	for _, day := range days {
		if day.Date.Before(nextMon) || nextFri.Before(day.Date) {
			d.Log.Info("next week not published yet", "week", key, "page_day", day.Date)
			return nil
		}
	}

	if err := d.Sender.Send(ctx, format.Week(days)); err != nil {
		return err
	}
	st.WeeklySent = key
	if err := d.State.Save(st); err != nil {
		// Do not fail: systemd would retry and send the menu again.
		d.Log.Error("weekly menu sent but state not saved; it may be sent again", "err", err)
	}
	return nil
}

// NotifyFailure posts the failure notice for unit, at most once per day.
func NotifyFailure(ctx context.Context, now time.Time, unit string, d Deps) error {
	today := menu.DateOf(now).String()
	st := load(d)
	if st.FailureNotified == today {
		d.Log.Info("failure notice already sent today", "unit", unit)
		return nil
	}
	if err := d.Sender.Send(ctx, format.Failure(unit)); err != nil {
		return err
	}
	st.FailureNotified = today
	if err := d.State.Save(st); err != nil {
		d.Log.Error("failure notice sent but state not saved", "err", err)
	}
	return nil
}

func fetchMenu(ctx context.Context, d Deps) ([]menu.Day, error) {
	body, err := d.Fetcher.Fetch(ctx)
	if err != nil {
		return nil, err
	}
	return menu.Parse(bytes.NewReader(body))
}

func load(d Deps) state.State {
	st, err := d.State.Load()
	if err != nil {
		d.Log.Warn("ignoring unreadable state", "err", err)
	}
	return st
}

func mondayOf(d menu.Date) menu.Date {
	offset := (int(d.Weekday()) + 6) % 7 // Monday=0 … Sunday=6
	return d.AddDays(-offset)
}
```

```go
// Command menubot posts the Casino Catering menu to Telegram.
// It runs once and exits; systemd timers decide when.
package main

import (
	"context"
	"flag"
	"fmt"
	"io"
	"log/slog"
	"os"
	"time"
	_ "time/tzdata" // the Pi image may lack zoneinfo; embed it

	"github.com/paulwyszynski/mri-casino-menu/internal/fetch"
	"github.com/paulwyszynski/mri-casino-menu/internal/jobs"
	"github.com/paulwyszynski/mri-casino-menu/internal/state"
	"github.com/paulwyszynski/mri-casino-menu/internal/telegram"
)

const defaultMenuURL = "https://casinocatering.de/speiseplan/"

const usage = `usage: menubot [--dry-run] [--now 2006-01-02T15:04] daily|weekly|notify-failure <unit>`

func main() {
	os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))
}

func run(args []string, stdout, stderr io.Writer) int {
	log := slog.New(slog.NewTextHandler(stderr, nil))

	fs := flag.NewFlagSet("menubot", flag.ContinueOnError)
	fs.SetOutput(stderr)
	fs.Usage = func() { fmt.Fprintln(stderr, usage) }
	dryRun := fs.Bool("dry-run", false, "print messages instead of sending; do not write state")
	nowFlag := fs.String("now", "", "override the current time (Europe/Berlin), format 2006-01-02T15:04")

	// Flags may come before or after the subcommand.
	if err := fs.Parse(args); err != nil {
		return 2
	}
	if fs.NArg() == 0 {
		fs.Usage()
		return 2
	}
	cmd := fs.Arg(0)
	if err := fs.Parse(fs.Args()[1:]); err != nil {
		return 2
	}
	rest := fs.Args()

	// Validate the command before config, so typos are reported as such.
	switch cmd {
	case "daily", "weekly":
	case "notify-failure":
		if len(rest) != 1 {
			fs.Usage()
			return 2
		}
	default:
		fmt.Fprintf(stderr, "unknown command %q\n%s\n", cmd, usage)
		return 2
	}

	loc, err := time.LoadLocation("Europe/Berlin")
	if err != nil {
		fmt.Fprintln(stderr, "load timezone:", err)
		return 2
	}
	now := time.Now().In(loc)
	if *nowFlag != "" {
		if now, err = time.ParseInLocation("2006-01-02T15:04", *nowFlag, loc); err != nil {
			fmt.Fprintln(stderr, "invalid --now:", err)
			return 2
		}
	}

	deps, err := buildDeps(*dryRun, stdout, log)
	if err != nil {
		fmt.Fprintln(stderr, err)
		return 2
	}

	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Minute)
	defer cancel()

	switch cmd {
	case "daily":
		err = jobs.Daily(ctx, now, deps)
	case "weekly":
		err = jobs.Weekly(ctx, now, deps)
	case "notify-failure":
		err = jobs.NotifyFailure(ctx, now, rest[0], deps)
	}
	if err != nil {
		log.Error("job failed", "job", cmd, "err", err)
		return 1
	}
	return 0
}

func buildDeps(dryRun bool, stdout io.Writer, log *slog.Logger) (jobs.Deps, error) {
	stateDir := os.Getenv("STATE_DIR")
	if stateDir == "" {
		stateDir = os.Getenv("STATE_DIRECTORY") // set by systemd StateDirectory=
	}
	if stateDir == "" {
		stateDir = "."
	}
	menuURL := os.Getenv("MENU_URL")
	if menuURL == "" {
		menuURL = defaultMenuURL
	}

	d := jobs.Deps{
		Fetcher: fetch.New(menuURL),
		State:   state.New(stateDir, dryRun),
		Log:     log,
	}
	if dryRun {
		d.Sender = printSender{w: stdout}
		return d, nil
	}
	token, chatID := os.Getenv("TELEGRAM_BOT_TOKEN"), os.Getenv("TELEGRAM_CHAT_ID")
	if token == "" || chatID == "" {
		return jobs.Deps{}, fmt.Errorf("TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID must be set (or use --dry-run)")
	}
	d.Sender = telegram.New(token, chatID)
	return d, nil
}

// printSender is the --dry-run sender.
type printSender struct{ w io.Writer }

func (p printSender) Send(_ context.Context, text string) error {
	_, err := fmt.Fprintf(p.w, "%s\n---\n", text)
	return err
}
```

- [ ] **Step 4: Write the Pi-side installer**

`deploy/install.sh`:

```bash
#!/usr/bin/env bash
# Runs on the Pi as root, from the directory deploy.sh copied the files to.
set -euo pipefail

src="$(cd "$(dirname "$0")" && pwd)"

id menubot >/dev/null 2>&1 \
  || useradd --system --no-create-home --shell /usr/sbin/nologin menubot

install -m 755 "$src/menubot" /usr/local/bin/menubot
install -m 644 "$src"/*.service "$src"/*.timer /etc/systemd/system/

install -d -m 755 /etc/menubot
if [ ! -f /etc/menubot/env ]; then
  install -m 600 "$src/env.example" /etc/menubot/env
fi

# Let time-sync.target wait for a real NTP sync (the Pi has no RTC).
systemctl enable systemd-time-wait-sync.service

# The failure template is checked indirectly through OnFailure=.
systemd-analyze verify \
  /etc/systemd/system/menubot-daily.service /etc/systemd/system/menubot-daily.timer \
  /etc/systemd/system/menubot-weekly.service /etc/systemd/system/menubot-weekly.timer
systemctl daemon-reload
rm -rf "$src"

# Do not start the timers while the config still has placeholder values.
if grep -q 'replace-me' /etc/menubot/env; then
  echo ">>> Fill in /etc/menubot/env (TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID),"
  echo ">>> then run ./deploy.sh again to enable the timers."
  exit 0
fi

systemctl enable --now menubot-daily.timer menubot-weekly.timer
systemctl list-timers 'menubot*' --no-pager
```

````markdown
# mri-casino-menu

Telegram bot that posts the [Casino Catering menu](https://casinocatering.de/speiseplan/) to a chat:

- **Mon–Fri 10:00** — today's menu (or a short notice if today isn't online)
- **Fri 15:00** — next week's menu; retried hourly until 20:00 if not published yet

Runs as a one-shot Go binary triggered by systemd timers on a Raspberry Pi (arm64).
Design: [`docs/superpowers/specs/2026-10-11-menubot-design.md`](docs/superpowers/specs/2026-10-11-menubot-design.md)

## Try it locally

```bash
go test ./...
go run ./cmd/menubot --dry-run daily
go run ./cmd/menubot --dry-run --now 2026-10-09T15:00 weekly
```

`--dry-run` prints instead of sending and needs no token.

## Set up on the Raspberry Pi

1. **Bot token** — from @BotFather (`/mybots` → your bot → *API Token*).
2. **Chat ID** — send a message in the chat, then:
   ```bash
   curl -s "https://api.telegram.org/bot<TOKEN>/getUpdates"
   ```
   Use the `"chat":{"id":…}` value (groups are negative, e.g. `-1001234567890`).
3. **Deploy** from your Mac (needs Go and SSH access to the Pi, e.g. host `pi` in `~/.ssh/config`):
   ```bash
   ./deploy.sh pi
   ```
4. **Configure** on the Pi:
   ```bash
   ssh pi sudo nano /etc/menubot/env
   ```
   ```
   TELEGRAM_BOT_TOKEN=123456789:AA...
   TELEGRAM_CHAT_ID=-1001234567890
   ```
   Then run `./deploy.sh pi` once more — the timers are only enabled when the config has no placeholder values.
5. **Test**:
   ```bash
   ssh pi /usr/local/bin/menubot --dry-run daily
   ssh pi sudo systemctl start menubot-daily.service
   ```

## Operations

| What | Command |
|---|---|
| Next runs | `ssh pi systemctl list-timers 'menubot*'` |
| Logs | `ssh pi journalctl -u menubot-daily -u menubot-weekly -u 'menubot-failure@*' --since today` |
| Update | `./deploy.sh pi` (keeps `/etc/menubot/env`) |
| State | `/var/lib/menubot/state.json` |

If fetching or parsing fails, systemd retries 3× (5 min apart) and then posts one ⚠️ notice per day to the chat.
````
